<h1>Project: Etch-a-Sketch</h1>
A simple drawing app with several features.
<br>
This project is based on <a href="https://www.theodinproject.com/">The Odin Project</a>.

<h3>Features</h3>

- Color picker

- Size adjustment

- Grid view

- Graduation mode

- Responsive Design implemented.

<h3>Tech Stack</h3>

- Frontend: HTML CSS JavaScript

- Icons: <a href="https://pictogrammers.com/">Pictogrammers</a>
